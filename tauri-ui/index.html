能力边界

1. 使用本地代理(API)会写入 openai_base_url = "https://localhost:3445/v1"、托管模型目录，并切到本地代理占位 API 登录态。

2. 代理 + 官方登录会保留/恢复 ChatGPT token，但 API 模型仍由本地代理使用上游配置里的 API Key 调用。

3. 模型目录由“模型路由”的客户端模型与展示名生成；Codex Desktop 是启动时读取配置，通常需要重启或新开会话后生效。

Trae 集成

Trae 官方登录通过本地扩展桥接到代理；这里集中查看桥接健康、命令能力与调试流入口。
正在检查 Trae Bridge 状态...

能力边界

1. Trae Bridge 依赖 Trae 扩展宿主的 127.0.0.1:17861 本地服务，代理只负责接入和转译。

2. 普通官方登录链路只能看到最终返回；Raw Stream Patch 属于诊断模式，可把 Trae 原始事件映射成 SSE 注释。

3. 可见过程模式会把安全摘要写入 assistant 正文，普通 SDK 也能看到，但会改变最终输出内容。

4. Raw Stream Patch 会修改 Trae 安装文件，可能触发“安装似乎损坏”的完整性警告；不建议作为常驻模式。
