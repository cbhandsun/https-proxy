正在检查 Claude Code 状态...

💡 使用说明与指引

1. 应用代理后，我们会将本地代理的 Base URL 和必要的 Token 写入 Claude Code 的用户配置目录中，所有 CLI 交互都会静默流经本地代理，并依据您的“模型路由”进行分发。

2. 恢复直连模式下，您可以运行官方 claude login 正常通过浏览器进行 OAuth 认证，之后再切换为代理模式即可继续使用本地节点。
